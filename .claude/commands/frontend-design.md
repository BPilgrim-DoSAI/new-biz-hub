# Frontend Design Skill

This skill specializes in building **distinctive, production-grade frontend interfaces** that prioritize design quality and avoid generic aesthetics.

## Core Purpose

Help create web components, pages, and applications with exceptional attention to aesthetic details and creative choices — not cookie-cutter designs.

## Before Coding

- Identify the interface's purpose and audience
- Commit to a bold aesthetic direction (minimalist, maximalist, retro, luxury, etc.)
- Note technical constraints
- Define one memorable differentiator

## Implementation Principles

**Typography**: Use distinctive, characterful fonts paired intentionally. Avoid generic fonts like Arial and Inter. Vary weight, size, and spacing to create hierarchy with personality.

**Color**: Build cohesive, committed palettes. Choose a dominant color and sharp accents. Avoid muddy in-between tones. Be decisive.

**Motion**: High-impact animations, often CSS-only. Use staggered reveals, scroll-triggered effects, entrance animations. Timing functions matter — prefer `cubic-bezier(0.16, 1, 0.3, 1)` for snappy-then-ease feel.

**Composition**: Unexpected layouts with asymmetry, overlap, and generous whitespace. Avoid equal padding and perfectly centred everything.

**Details**: Atmospheric backgrounds, textures, gradients, subtle noise, custom cursors, hover micro-interactions. These separate memorable from forgettable.

## What to Avoid

- Generic AI-generated aesthetics
- Overused typefaces (plain sans-serifs with no character)
- Clichéd color schemes (especially purple gradients)
- Predictable card-grid-plus-hero layouts with no variation
- Designs that could belong to any brand

## Complexity Matching

Implementation complexity should match the aesthetic vision. Maximalist designs require elaborate code. Refined, minimal designs demand precision and restraint. Neither is wrong — inconsistency is.
